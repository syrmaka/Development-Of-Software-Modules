# Практическая работа 1. Сборка иерархии проекта

## Что было дано

Архив с 17 файлами проекта **Cafe Report** без структуры: код, данные, тесты, документы и настройки лежали в одной куче.

## Что сделано

- Создана корневая папка `cafe-report`.
- Файлы разложены по папкам согласно их ответственности:
  - `app/services/` — расчёты и отчёт
  - `app/utils/` — работа с суммами и строками
  - `data/` — данные (`orders.csv`)
  - `docs/` — описание проекта
  - `tests/` — тесты
- В каждую папку с кодом добавлен `__init__.py`, чтобы Python считал её пакетом.
- Файлы переименованы в формат `snake_case` (латиница, нижнее подчёркивание).
- `читать меня.md` переименован в `README.md`.
- В корень добавлены `requirements.txt` и `.gitignore`.
- Удалены лишние файлы: кеш Python, служебные файлы ОС, черновики и старая версия программы.
- Проект собран и отправлен в репозиторий курса `student-tools`.
